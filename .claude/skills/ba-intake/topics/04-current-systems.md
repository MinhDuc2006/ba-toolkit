# Current systems and tools

## Goal
Map the technology landscape the process depends on.

## Core questions
1. Which systems, software, or tools are used in this area (including spreadsheets and paper)?
2. What is each one used for, and who owns it?
3. How do the systems connect? Is data re-entered manually anywhere?
4. Are any systems being replaced, or already out of support?
5. Are any tools or vendors mandated or off-limits?

## Follow-up probes
- Where are the workarounds (shadow spreadsheets, copy-paste, email)?
- How old is each system, and how happy are users with it?
- Who supports these systems (internal IT or a vendor)?

## Captures
System inventory (name, purpose, owner, users), integrations/manual handoffs, lifecycle status, constraints on tools.
