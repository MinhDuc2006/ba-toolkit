# Key processes

## Goal
Get a high-level view of the workflows in scope, to be detailed later with /ba-process.

## Core questions
1. What are the main processes in scope? Name them start to finish (e.g. "order to delivery").
2. For the most important one: what triggers it, what are the main steps, and what is the end result?
3. Who does each step?
4. How often does it run, and how long does it take end to end?
5. Is the process documented anywhere, and is that document accurate?

## Follow-up probes
- Where does work wait, get handed off, or get redone?
- What exceptions or special cases happen often?
- How does it differ between teams, sites, or shifts?

## Captures
Process list, for each one: trigger, main steps, actors, frequency/volume, cycle time, documentation status.
