# Data and metrics

## Goal
Know which numbers exist, so findings and recommendations can be backed by evidence.

## Core questions
1. Which KPIs or reports are tracked today in this area?
2. What are the current figures (volumes, cycle times, error rates, costs)?
3. Where does that data come from, and how reliable is it?
4. Is there data that people want but can't get?
5. Can I have samples (exports, reports, dashboards) to put in inputs/?

## Follow-up probes
- Who uses these reports, and what decisions do they make with them?
- Are there disagreements about "which number is right"?

## Captures
KPI list with current baseline, data sources and quality, reporting gaps, available samples.
