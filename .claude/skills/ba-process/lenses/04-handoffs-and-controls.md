# Handoffs and controls

## Use for
Tightening the "too loose" parts of the process — where work changes hands or rules are applied.

## How to apply
- Mark every handoff between lanes (people or systems). For each, note the mode (system, email, verbal, paper) and link it to the system map `H-` ID if one exists.
- Mark every decision or approval: is the rule written down? Is it applied consistently? Is there an audit trail?
- In the to-be, aim for fewer handoffs, clear owners per step, and rules applied at the earliest point (prevent errors rather than catch them).

## Questions to ask
- When work is passed on, how does the next person know it's ready and complete?
- Who decides at this approval, and on what basis?

## Technique note
Every handoff is a chance for delay, error and lost accountability. Counting handoffs as-is vs to-be is a simple, persuasive metric.
