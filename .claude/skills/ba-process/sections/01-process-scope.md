# Process scope (SIPOC)

## Purpose
Fix the boundaries of the process before mapping it, so everyone agrees where it starts and ends.

## How to write
- Name, owner, trigger (start event), outcome (end event), frequency/volume.
- SIPOC table: Suppliers → Inputs → Process (5–7 high-level steps) → Outputs → Customers.
- List what is explicitly out of scope (adjacent processes).

## Format
- **Process:** … · **Owner:** … · **Trigger:** … · **End:** … · **Volume:** …

| Suppliers | Inputs | Process (high level) | Outputs | Customers |
|---|---|---|---|---|
| | | 1. … | | |

**Out of scope:** …

## Technique note
SIPOC is a one-page scoping tool from Six Sigma. Agreeing the start and end events first prevents the map from sprawling.
