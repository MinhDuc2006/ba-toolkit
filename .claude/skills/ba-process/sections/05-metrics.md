# Process metrics

## Purpose
Quantify the as-is so the to-be improvement can be measured.

## How to write
- Calculate from the step table; show working briefly. Use `TBD` where inputs are missing.
- Cycle time = sum of touch + wait along the main path. Process efficiency = VA touch time ÷ cycle time.
- Include counts: steps, handoffs, decision points, NVA steps, manual handoffs.
- Fill the to-be column after the to-be is designed.

## Format
| Metric | As-is | To-be (estimate) | Change |
|---|---|---|---|
| Cycle time (main path) | | | |
| Touch time | | | |
| Process efficiency (VA ÷ cycle) | | | |
| Steps / NVA steps | | | |
| Handoffs / manual handoffs | | | |
| Error/rework rate | | | |
| Volume per week | | | |

## Technique note
Baseline numbers turn "it feels slow" into a business case. Even rough estimates are better than none — just label them.
