# Audience: business analysts (you and other BAs)

## Who
You later, a BA joining the engagement, a reviewer, or whoever takes over. They need to understand *what was found, why, and how it connects*.

## Style rules
- Complete and traceable: keep all IDs (C-, H-, P-, T-, CH-, G-, RC-, R-, BR-, SR-, FR-, NFR-, US-) and link to the output file each comes from.
- Show reasoning and evidence: sources, assumptions, confidence, and what's still unverified.
- BA terminology is fine; define engagement-specific terms in the glossary.
- Tables over prose; diagrams in Mermaid where they help.
- Record decisions and changes with dates, so the history is clear.
- Include **Technique notes** when learning_mode is on.

## Header / footer
Header per CLAUDE.md: title, engagement, date, sources used, open questions. Footer: open questions and next steps.
