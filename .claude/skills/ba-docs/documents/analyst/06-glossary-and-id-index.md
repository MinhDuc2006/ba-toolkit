# Glossary and ID index

## Purpose
Help any reader decode the engagement: business terms, acronyms, and every ID used across documents.

## Inputs
All outputs and context.md.

## Structure
1. **Glossary** — engagement-specific terms and acronyms (company jargon, system names, BA terms used) with plain definitions.
2. **ID prefix key** — what each prefix means and which file defines it (C-, H-, P-, T-, CH-, G-, RC-, R-, BR-, SR-, FR-, NFR-, US-, A-, D-, Q-).
3. **ID index** — every ID with a short title and its defining file, sorted by prefix. If very long (> ~150 rows), include only C-, G-, RC-, R-, BR- and link to source files for the rest.

## Format
| ID | Title | Defined in |
|---|---|---|
| RC-01 | No single order entry point | outputs/03-gap.md |

## Quality checks
- No ID in any output is missing from the index (within the size rule above).

## Technique note
A shared vocabulary avoids the most common BA failure: two stakeholders agreeing on words while meaning different things.
