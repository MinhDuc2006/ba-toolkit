# Roadmap and decisions needed

## Purpose
Show what happens when, how success will be measured, and exactly what leadership must decide.

## Inputs
03-gap roadmap and recommendation KPIs; 04-requirements priorities; context.md › Constraints.

## Structure
1. **Roadmap**: Now / Next / Later, each with 2–4 plain-language actions and the result expected.
2. **How we'll measure success**: 3–5 KPIs, baseline → target, checkpoint date.
3. **Decisions needed**: table with the decision, options, recommendation, deadline, and impact of delay.
4. **Risks to watch**: top 3, with the owner.

## Format
| Decision | Options | Recommended | Needed by | If delayed |
|---|---|---|---|---|
| Approve quick-win budget | Yes / No / Partial | Yes | 2026-12-01 | Peak-season delays continue |

## Quality checks
- Each decision is something the audience can actually decide.
- KPIs match those in 03-gap.

## Technique note
(Analyst reference only.) Separating "for decision" from "for information" respects executive time and gets faster approvals.
