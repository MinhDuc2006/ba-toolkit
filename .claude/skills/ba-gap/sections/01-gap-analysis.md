# Gap analysis (current vs target)

## Purpose
Show, dimension by dimension, where the organisation is today versus where it needs to be.

## How to write
- Group rows by dimension (one `###` per file in `dimensions/` that has at least one gap).
- Current state from evidence (context.md, system map, process maps). Target state from agreed goals/success metrics.
- Size: High / Medium / Low, based on impact on the goals.
- Note the symptoms that reveal the gap (the pain points people describe).

## Format
### <Dimension>
| ID | Current state | Target state | Gap | Symptoms | Size | Links | Source |
|---|---|---|---|---|---|---|---|
| G-01 | Orders re-keyed from paper | Orders captured once at source | No single entry point | Typos, 2 h delays | High | C-01, H-01, P-02 | 01-system-map.md |

## Technique note
Gap analysis = current state + target state + the difference. Writing the target in measurable terms makes the gap concrete and the recommendations testable.
