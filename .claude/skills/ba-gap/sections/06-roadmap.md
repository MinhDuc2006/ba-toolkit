# Roadmap

## Purpose
Sequence the recommendations into a realistic plan.

## How to write
- Three horizons: **Now** (0–3 months, mostly quick wins), **Next** (3–6 months), **Later** (6–12+ months, big bets).
- Respect dependencies and context.md constraints (budget cycles, freeze periods, deadlines).
- For each horizon: recommendations, the outcome expected, and the KPI checkpoint.

## Format
| Horizon | Recommendations | Expected outcome | KPI checkpoint |
|---|---|---|---|
| Now (0–3 m) | R-01, R-03 | … | Order delay < 1 h |
| Next (3–6 m) | | | |
| Later (6–12 m) | | | |

## Technique note
Now/Next/Later roadmaps avoid false precision while still showing order and dependencies — ideal before budgets and dates are confirmed.
