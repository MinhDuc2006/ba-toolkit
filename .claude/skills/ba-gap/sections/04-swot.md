# SWOT

## Purpose
Put the gaps in context: what the organisation can build on, and what outside forces matter.

## How to write
- Strengths/Weaknesses are internal (from system map 🟢 and 🟠/🔴 items, people, processes). Opportunities/Threats are external (customers, competitors, regulation, technology trends, suppliers).
- 3–6 points each, specific to this engagement's scope — not generic.
- Finish with 2–4 "SO / WT" lines: how strengths can capture opportunities, and which weaknesses expose the business to threats.

## Format
| | Helpful | Harmful |
|---|---|---|
| **Internal** | **Strengths**<br>- … | **Weaknesses**<br>- … |
| **External** | **Opportunities**<br>- … | **Threats**<br>- … |

**Strategic implications**
- SO: …
- WT: …

## Technique note
A SWOT is only useful when it leads to implications. The cross-pairs (SO, ST, WO, WT) — the TOWS matrix — turn a list into strategy.
