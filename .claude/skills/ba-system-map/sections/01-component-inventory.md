# Component inventory

## Purpose
List every part of the current system in scope, so nothing is assessed from memory.

## How to write
- Include software, spreadsheets, paper forms, shared inboxes, teams/roles, external parties and data stores.
- Include workarounds the user mentioned — they are real components.

## Format
| ID | Component | Type | Purpose | Owner | Users | Source |
|---|---|---|---|---|---|---|
| C-01 | Order spreadsheet | Spreadsheet | Tracks daily orders | Store manager | Shift leads | context.md › Current systems |

## Technique note
A context/inventory list is the BA's first defence against blind spots. Shadow tools (spreadsheets, WhatsApp groups) are often where the real system lives.
