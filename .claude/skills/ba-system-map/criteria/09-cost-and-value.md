# Cost and value

## Looks at
Whether what the part costs (licences, staff time, errors, rework) is justified by the value it delivers.

## Signs it is too loose
- No one knows what it costs; licences or subscriptions with no owner; overlapping tools doing the same job.

## Signs it can be improved
- Value is clear but staff time spent on it is high (manual effort that could be reduced).

## Signs it needs more work
- Cost clearly exceeds value, or costs are rising fast (e.g. vendor price increase, growing rework).

## Questions to ask
- Roughly how many hours a week go into running or working around this?
- What would happen if we switched it off tomorrow?
