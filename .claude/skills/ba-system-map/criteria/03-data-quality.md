# Data quality and single source of truth

## Looks at
Whether data is accurate, complete, timely, and held in one agreed place.

## Signs it is too loose
- Same data held in several places with no master; "which number is right?" debates.
- No validation on entry; free-text fields used for structured data.

## Signs it can be improved
- Data is right but slow to get or needs manual cleaning for reports.

## Signs it needs more work
- Known errors cause wrong decisions, customer complaints, or financial loss.

## Questions to ask
- Where is the "true" version of this data?
- How often is it wrong, and how do you find out?
