# Sample case — Harbour Lane Coffee Co. (fictional)

A 12-store coffee chain planning to grow to 17 stores. Stock ordering runs on paper counts, per-store Excel files, email, WhatsApp and a 9-year-old warehouse system. The sponsor wants fewer stockouts, less waste, and an ordering process that scales.

All people, companies and figures are invented for practice.

## Inputs
| File | What it is |
|---|---|
| `inputs/01-kickoff-meeting-notes.md` | Sponsor's goals, constraints, budget |
| `inputs/02-interview-store-manager.md` | How stores count and order |
| `inputs/03-interview-warehouse-coordinator.md` | Re-keying, picking, purchasing |
| `inputs/04-interview-finance.md` | Waste figures, staff rates, budget rules |
| `inputs/05-ops-data-summary.md` | 12 weeks of stockouts, errors, couriers |

Deliberately included for practice: a conflict between sources (waste ≈ $250k vs $182k), missing data (lost sales, store stock levels), a key-person dependency, and a shared login.

## Outputs
Generated by running every skill with `--no-questions`, so each document lists the questions it would have asked under *Open questions*. In a real engagement you'd answer those in the interview step.
